# Italy Itinerary Guide

The plain-English guide to the Tour d'Italia itinerary app.

Live: https://turbocheese.github.io/Italy_Itinerary_Guide/

## Deploying
Upload the **contents** of this folder to the repo root, then
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

- `index.html` — the guide
- `support.js` — runtime, required
- `icon.svg` — favicon
- `.nojekyll` — stops Jekyll from touching the files
